Water balance: where the 200 litres goGiven in this example

The tank starts empty. Of 600 L entering, 400 L fits and 200 L overflows. This simplified event ignores leaks, evaporation, and water use during rainfall.

Incoming water = added storage + overflow
600 L = 400 L + 200 L

Start with 100 L already in the same tank and only 300 L of space remains: overflow becomes 300 L.

Uncertainty: storage capacity is only one constraintOutside this model

Flow rate, drainage, maintenance, and water quality are not represented. A larger tank changes the capacity calculation but does not establish whether a real installation is suitable.

Keep limitations beside the conclusion they qualify. A precise number can still describe a very simple model.
