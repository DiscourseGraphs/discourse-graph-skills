# Rainwater explanation example

An illustrative template for communicating a complex idea with a visible overview and optional detail. All content and quantities are fictional. This is a proposal/example, not an adopted team standard.

Open `example.html` in a browser. It embeds its styles, controller, tokens, and license. Reference links are optional. Edit the fragments and CSS, then rebuild from this directory:

```sh
python ../../scripts/bundle_html.py --config page.json --output example.html --force
```

## Review checklist

At desktop and 390px widths, check for overflow, readable labels, a visible overview, and closed initial disclosures. Exercise group/card controls after individual toggles, scoped controls, search/clear, navigation into closed sections, tabs by keyboard, focus, and theme switching. With JavaScript disabled, both tab panels and native disclosures should remain usable. Check the file offline for missing assets and network requests. Notes are intentionally unsaved.
